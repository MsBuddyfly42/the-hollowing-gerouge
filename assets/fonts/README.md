# Locally packaged typefaces

Cinzel variable font — headings and controls.
Crimson Pro variable font — narrative and evidence text.

Downloaded from the Google Fonts public font repository on October 17, 2026. Both use the SIL Open Font License; the complete license and attribution notices are included beside the fonts in `Cinzel-OFL.txt` and `CrimsonPro-OFL.txt`. Font files are served locally so the game does not depend on a font CDN.

Sources:
https://github.com/google/fonts/tree/main/ofl/cinzel
https://github.com/google/fonts/tree/main/ofl/crimsonpro
