# Gerouge scenery

Three locally packaged WebP photographic environment plates, generated specifically for this fictional Gerouge project on October 17, 2026. No Nevermore assets are copied. Original generated PNGs were encoded as WebP at quality 90 without cropping, so hotspot coordinates refer to the entire 1672 × 941 image.

- `approach.webp` — manor approach, gates, ribbons, plaque, workbench lantern, front doors.
- `hall.webp` — grand stair, study doorway, bell rope, flower table, portrait, console drawer.
- `study.webp` — writing desk, lower book cabinet, eight-girl portrait, papers, lamp, pigment.

Total packaged scenery is approximately 1.27 MB. No remote image host is required by the new photographic route.
